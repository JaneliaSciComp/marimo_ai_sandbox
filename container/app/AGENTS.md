# Janelia HPC cluster hints

Before suggesting or running anything that touches the Janelia compute
cluster (LSF/`bsub`, `/groups`, `/nrs`, `/scratch`, Apptainer, module
system, GPU queues, etc.), fetch this page for current, cluster-specific
guidance:

https://hpc.int.janelia.org/docs/ai-agent-hints

It covers scheduler details (LSF, not Slurm), storage tiers and quotas,
GPU queue/slot sizing, common agent mistakes (e.g. suggesting Docker or
SSH tunnels), and billing. It is kept up to date at that URL — prefer
fetching it live over relying on any cached/pasted copy older than ~30
days.
